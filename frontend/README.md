# Frontend

This React application contains the workshop screens. `src/App.js` defines the routes and restores the staff login; `src/pages/` contains the screens; `src/styles/` contains their styles. The API runs separately on `http://localhost:5000`.

From this folder, run `npm ci` after cloning, then `npm start`. Open `http://localhost:3000`. Keep the MySQL server and backend running at the same time. See the project root `README.md` for the full setup, including the database and WhatsApp.
